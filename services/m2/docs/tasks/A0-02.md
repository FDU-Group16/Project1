## 约束、方案与依赖

使用 Python 3.12 标准库 frozen dataclass；集合转为 frozenset 快照，输入拒绝字符串冒充集合。Actor 只承载可信适配器的结果，不验证令牌、不授予权限，空范围与全局范围保留区别。TimeRange 必须使用带时区的 datetime，先转 UTC 再比较，拒绝空或反向区间；半开区间的边界相邻不重叠。时间格式序列化和公开 DTO 留待后续接口批次。

本批不选择同步/异步数据库方案，不实现两级审批、自批限制、截止公式等待决政策；没有真实数据和服务配置，也不连接数据库。M2-BASE 只完成这两个类型，Base/UoW/模型/端口/装配尚待实现。
