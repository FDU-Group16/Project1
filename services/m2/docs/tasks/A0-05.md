## 方案与边界

同步 SQLAlchemy Session，顶层用例显式 `commit()`；未提交或异常退出一律 rollback/close，沿用已有内部协议而非自动提交。每个 UoW 只使用一次，拒绝嵌套/完成后的访问；port 共用传入的 session，仅 flush，不独立 commit。无导入时联网，无通用 DATABASE_URL 回退，连接参数不得进入日志。

Base 的 metadata 固定 `m2` schema；初始迁移仅建立 schema 和 Alembic 版本基点，无申请/审批业务表。迁移使用显式 M2 专用 URL；数据库测试额外要求显式启用及核对回环主机、指定端口、专用库/账号，拒绝未经确认的目标。测试使用随机命名探针表，清理只针对自己创建的表。

隔离测试：PostgreSQL 18、127.0.0.1:55432（占用则另选空闲端口并登记）、m2_a_test 库/m2 schema、m2_a_test 非超级用户；独立 bootstrap 管理员创建测试库。私有集群、密码、日志与 PID 只在忽略的本地运行目录。允许必要时 Homebrew 安装 postgresql@18 及必要依赖，禁止 auto-update、upgrade、brew services，不使用默认集群/共享 .env。测试完只停止本轮私有服务。

无外部替身，不调用 M1/D。探针表用于真实事务测试，不是申请服务替身。业务资格、审批层级、截止和资源政策仍 proposed；没有注册 HTTP、申请保存查询、A/B 业务集成或部署。
