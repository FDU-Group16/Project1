本任务由 M1 负责人明确要求将原型实现为 Vue 并发布至测试站点，具体团队评审人员尚未登记。为避免示例房间或预约被误认为真实可用信息，普通业务入口明确显示服务未接入，仅在独立只读示例入口展示合成数据，并持续标注非实时信息；不收集账号密码、不创建身份、不执行预约/取消/签到。使用原生表单标签、可见键盘焦点、跳过导航与移动菜单，验证范围和结果见 [实施记录](../apps/web/docs/vue-interface-implementation.md)。实际身份、院系访问公平性、屏幕阅读器完整验收、真实数据保留和服务端越权仍待后续接口任务验证。

## 2026-10-22：M1 与 D-02 实施

用户确认本次只承担 M1 和 D-02；D-01/03/04仍由相应组推进，不能将开发身份当真实认证。实施控制包括：后端院系/预约所有权校验；独立数据库账号/schema；不记录密码、令牌、签到码；统计聚合不返回学生ID；动态码仅管理身份可查看；违约只记录事实，不增加自动封禁。合成身份与模拟通知在界面和输出显式标注，普通模式不回退。

软注销保留历史引用，避免删除导致无法解释既有预约；对停用影响与跨服务并发窗口在主任务记录。界面使用标签、错误提示、键盘焦点及窄屏布局，真实API和可访问性证据见 [实施交接](../services/m1/tasks/2026-10-22-completion.md)。
