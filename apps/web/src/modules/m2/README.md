# M2 前端模块

M2 组维护本目录：`pages/` 存放页面，`components/` 存放模块私有组件，`routes.ts` 管理 `/m2` 下的路由。目前有模块入口和本地草稿预览，业务提交与审批尚未实现。

当前 `/m2` 是能力入口，`/m2/apply` 可本地检查申请草稿并转换 UTC。草稿没有保存、提交或占用教室，真实申请和审批仍待后端公开接口。交接与验证见 [STATUS.md](STATUS.md) 和 [前端集成任务](docs/2026-10-29-frontend-integration.md)。

在首个已评审的 M2 业务接口任务中创建 `api.ts`，结合公共 `shared/api/` 封装请求。审批成功后的 M1 状态写回由后端完成；前端不自行调用内部写回接口。模块状态留在本目录，不导入其他模块的私有实现。
