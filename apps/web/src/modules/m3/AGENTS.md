# M3 前端规则

遵守仓库根和 `apps/web/AGENTS.md`。本目录拥有报修工作台、工单表单与详情、API 适配和前端交接记录；不得导入 M1/M2 私有代码。

- 接口及状态以 `contracts/m3-work-orders.md` 为准。权限操作显示使用后端 `allowedActions`，真实授权仍由后端执行。
- 维修下架和验收恢复由后端同步；等待回执时如实展示等待，不提前显示成功或由浏览器调用 M1。
- 统一使用 `shared/auth` 的登录、退出和过期处理；API 使用 `shared/api/client.ts`。不消费 context 中的开发令牌、不另建 M3 身份选择或存储。监听共享 auth.epoch，身份变化立即取消请求和清理旧页面。
- 本地演示也通过公共 `/login` 的显式开发身份入口。模块只展示依赖模式，不根据前端权限或用户自报角色替代后端授权。
- 新增依赖记录写在本目录 `DEPENDENCIES.json`，D-01 公共替身由共享身份目录维护；不把真实客户端和业务页面标为待删除替身。
- 不安装额外依赖。样式限制在 M3 容器内，复用现有公共主题和组件。
- 完成修改更新 STATUS。类型检查、真实浏览器验证和真实 M1/D 集成证据分别记录，不能用开发替身证据代替真实联调。
