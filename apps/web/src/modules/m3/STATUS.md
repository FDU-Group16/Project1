## 已实现与可用入口

- [模块路由](routes.ts) 和 [模块壳](pages/ModuleHome.vue)：`/m3` 工单中心、`/m3/new` 上报、`/m3/orders/:id` 详情；沿用公共 Vue 应用与组件。
- [工单列表](pages/WorkOrdersPage.vue)：可见范围由后端决定，展示状态统计、标题/房间/编号搜索、状态筛选和加载/空/错误状态。
- [上报表单](pages/NewOrderPage.vue)：字段校验、真实 API 提交、幂等键与不确定结果重试。
- [工单详情](pages/OrderDetailPage.vue)：派单/重派、开修、完工、验收/返工、取消、一次评价、服务端操作历史。按身份展示动作，服务端承担实际授权。
- [API 适配器](api.ts) 与 [模块 session](session.ts)：同源请求、明确失败、切换身份取消旧请求并清空数据、迟到响应隔离、详情 GET 不覆盖更新的动作结果。
- 角色和房间使用显式开发依赖时明确标识；正式身份未接入时没有业务入口。`STARTING_REPAIR`/`ACCEPTING` 展示同步等待；失败显示问题，调度可向后端请求检查重试资格。
