# M1 Vue 界面实施记录

日期：2026-10-22。父任务：[通用 Vue 界面与 M1 页面实现](../../../../docs/vue-interface-implementation.md)。授权范围为本模块页面、组件、路由、只读样例和交接文档；公共集成由父任务负责。

## 需求与交付范围

关联 M1-01、M1-02、M1-06 的页面展示，以及 M1-03 的基础时段输入校验。D-01 身份和 D-02 主数据、M1 搜索/预约 API 仍未接入；对应完整业务需求仍未完成。

- `/m1`：日期、开始/结束整点、插座筛选与校验，显示“座位查询服务尚未接入”。有效提交只说明条件已检查，不生成查询结果。
- `/m1/reservations`、`/m1/reservations/:id`：列表与详情页面框架，显示“身份服务尚未接入”，不展示任何用户记录。
- `/m1/preview`：显式只读入口，使用合成房间、座位样例展示筛选、空结果、网格选择和属性；占用/停用样例不可选择。
- `/m1/preview/reservations`、`/m1/preview/reservations/:id`：当前/历史样例与独立详情路由；不存在的样例 ID 显示清晰空态。
- 每个展示页顶部持续显示“示例数据，非实时可约信息”；没有预约创建、取消、签到按钮或伪造身份。

## 状态与边界

代码见 [搜索页](../pages/ModuleHome.vue)、[预约列表](../pages/ReservationsPage.vue)、[详情页](../pages/ReservationDetailPage.vue)、[房间/座位组件](../components/ExampleRooms.vue)、[查询输入逻辑](../search.ts) 和 [路由](../routes.ts)。

日期采用 Asia/Shanghai；查询参数保存 date、start、end、socket、searched，刷新及浏览器前后退可恢复。输入变动将 searched 置为 0 并销毁旧结果与座位选择；重新筛选后才展示结果。选择状态仅存在当前组件内，不持久化身份、预约或个人数据。当前/历史范围保存在 tab 查询参数中。

整点选择覆盖 00:00–24:00，要求结束时间晚于开始时间。四小时默认上限依据需求基线 M1-03，未来须由已评审的配置接口提供；本次不实现配置管理。普通页面不根据示例开放时段限制查询，实际开放窗口及权限由后端决定。预览中 08:00–22:00 / 09:00–22:00 只是房间样例属性，不是服务规则。

展示模型位于 [preview/fixtures.ts](../preview/fixtures.ts)，用途见 [说明](../preview/README.md)。这些模型不是前后端契约，也没有 API 适配器、开发模拟服务或失败回退；普通入口的任何查询都不会激活样例。既有 contracts/m1-room-blocks.openapi.json 0.1.0-proposed 仅是跨服务写回提案，不在本任务调用范围内。未创建 api.ts、接口字段、数据库表或迁移。

## 可访问性与界面

所有表单字段具有标签；日期和时段错误通过 aria-invalid 与 aria-describedby 关联，可用键盘提交并定位错误字段。座位是具有名称、选中状态的按钮；停用/占用不可选，颜色之外有文字说明。展开座位后聚焦详情标题，收起后焦点返回原房间按钮。详情采用路由，不引入弹窗焦点陷阱。窄屏筛选可换行，680px 以下输入使用 16px 字号。
