# M1 前端模块

M1 组维护本目录：`pages/` 存放搜索、预约列表与详情，`components/` 存放模块私有组件，`routes.ts` 管理 `/m1` 下的路由。普通入口显示未接入状态；`/m1/preview` 下的页面使用 `preview/` 中合成样例提供只读界面浏览，不执行预约或身份验证。实现和真实接口缺口见 [STATUS](STATUS.md) 与 [实施记录](docs/vue-interface.md)。

在首个已评审的 M1 业务接口任务中创建 `api.ts`，结合公共 `shared/api/` 封装请求。模块状态留在本目录，不导入其他模块的私有实现。新增子页面只需在本模块登记路由；公共导航变更另行协调。
