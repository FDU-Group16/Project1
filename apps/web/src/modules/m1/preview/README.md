# 只读界面样例

`fixtures.ts` 仅为 `/m1/preview`、`/m1/preview/reservations` 及其详情提供合成展示模型。所有房间、编号和记录均为示例，不代表实时可约信息、真实身份或已经产生的预约。

普通 `/m1` 和 `/m1/reservations` 不读取样例来响应查询，不会在真实服务失败时回退到样例。这里没有 API、提供方模拟、凭据、业务写入或个人数据持久化。展示模型不能视为已约定的前后端契约。

后续真实接口任务须由 M1 与 D 组评审契约，接入真实 API 并验证身份隔离、可约状态和错误行为。该任务再决定是否保留这个显式只读展示入口；不能仅凭样例数据移除业务校验或判定联调完成。
