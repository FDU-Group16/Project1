# 通用前端交互原型

本目录保存 2026-10-22 设计讨论的独立原型，供 M1/M2/M3 评审公共布局、登录入口和 M1 页面风格。

- [common-frontend.html](common-frontend.html)：可直接用浏览器打开的独立预览；部分图标与展示辅助脚本需要网络，离线表现未验证。
- [common-frontend.fragment.html](common-frontend.fragment.html)：可编辑的原型片段；布局、样式与交互位于该文件。
- [通用方案](../common-frontend-design.md)：公共页面、组件、身份状态、分工及验收。
- [M1 方案](../../src/modules/m1/docs/frontend-design.md)：M1 页面与业务边界。

可演示模块导航、日期/时段与插座筛选、房间座位选择、预约详情、当前/历史切换及登录入口。日期、房间、用户、余量、预约状态均为固定合成样例；“进入登录后预览”只切换画面，不校验凭据。

原型不调用业务 API，不创建预约，不接入 Vite 路由、服务或部署。它不是运行时临时依赖或登录实现。只有设计中明确列出的本地交互已经验证，实际认证、权限隔离和跨模块集成需后续实施与验收。

独立文件由可编辑片段使用 visualize 的 scripts/render.py 导出；修改片段后需重新导出并检查浏览器交互及 320px 窄屏。查看已导出的 HTML 不需要该工具或应用开发环境。
